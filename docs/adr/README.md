# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for Happy Trails.

Use an ADR when an experimental question has been resolved well enough to make a durable architectural choice that future contributors should understand.

Suggested naming:

```text
ADR-001-short-decision-title.md
ADR-002-short-decision-title.md
```

Each ADR should include:

- Status
- Context
- Decision
- Alternatives considered
- Consequences
- Evidence / related spikes

Spike documents answer experimental questions. ADRs record the decision made from that evidence. Do not use ADRs as general design notes or changelog entries.
